# 有线连接的 USB 接口

在 **设置 → 连接 → 有线连接 → 使用接口** 中选择 iPhone 所连接的位置：

- **扶手箱 USB**：默认选项。
- **点烟器旁 USB**：前排储物区域内的接口。

设置在下次有线连接时生效。连接过程中修改选项，只保存选择；请先停止当前连接，再更换接口并重新点击“有线连接”。

06Link 仅为选中的接口开启数据模式，不自动尝试另一个接口。接口已经处于数据模式时不会重复切换；退出连接后按记录恢复本次修改的原模式。其他接口可以继续交给原车管理。

## E01 对应关系

| 位置 | 数据模式控制入口 | 已观察到的 USB 路径 |
| --- | --- | --- |
| 扶手箱 | `/sys/class/host_peripheral/charging_mode` | `1-1.2` |
| 点烟器旁 | `/sys/class/otg_peripheral/charging_mode` | `1-1.1` |

以上对应关系适用于已验证的 BX11QJ / E01 Android 5.1 车机。设备路径用于核对实际连接位置，不作为其他车型的通用编号。

仅充电模式下，手机尚未在 USB 总线上被识别，充电状态也不能区分 iPhone 与其他设备。因此使用明确的接口选择，不通过轮流切换两个接口来探测手机。
