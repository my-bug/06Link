# 有线连接的 USB 接口

在 **设置 → 连接 → 有线连接 → 使用接口** 中选择连接方式。

- **扶手箱 USB** 是默认选项，适用于车内扶手箱的接口。
- **点烟器旁 USB** 适用于前排点烟器旁的接口。
- **原生 USB** 使用安卓设备自身的 USB 接口。在支持 USB 主机模式的平板上选这一项，用数据线接上 iPhone，点击“有线连接”。如果系统询问是否允许 06Link 访问 USB 设备，选择允许。

设置在下次有线连接时生效。如果已经连上，请先停止当前连接，再按新设置连接。

选择车内接口时，06Link 只为选中的接口开启数据模式，其他接口仍由原车管理。接口已处于数据模式时会直接使用。退出连接后，06Link 会恢复本次改过的接口模式。选择“原生 USB”时，接口由安卓系统管理。

## E01 对应关系

| 位置 | 数据模式控制入口 | 已观察到的 USB 路径 |
| --- | --- | --- |
| 扶手箱 | `/sys/class/host_peripheral/charging_mode` | `1-1.2` |
| 点烟器旁 | `/sys/class/otg_peripheral/charging_mode` | `1-1.1` |

以上对应关系适用于已验证的 BX11QJ / E01 Android 5.1 车机。设备路径用于核对实际连接位置，不作为其他车型的通用编号。

仅充电模式下，手机尚未在 USB 总线上被识别，充电状态也不能区分 iPhone 与其他设备。因此使用明确的接口选择，不通过轮流切换两个接口来探测手机。
