# 工程结构

仓库根目录就是实际开发目录。日常修改、构建和 GitHub 更新均在这里完成，没有另一份发布用源码树。

```text
06Link/
  src/
    e01/                  # 全部参与编译的适配 Java
    core/smali/           # 其余完整运行源码
    main/                 # Manifest / res / assets / jniLibs / resources
    oem-bluetooth/        # 当前原车蓝牙兼容组件与脚本
    display-clock/        # 当前显示时钟实现
  scripts/                # 正式构建、工具解析、离线检查
  tooling/
    manifest.json         # 公开工具版本、来源和哈希
    compile-stubs/        # 仅编译使用的接口，不进入 APK
    java/                 # 签名工具源码
  tests/                  # 行为测试、固定夹具、源码集成契约
  gradle/wrapper/         # 固定 Gradle 启动器
  .github/                # CI 与反馈模板
  docs/                   # 必要工程说明
  project.json            # 版本与输入配置
  build.gradle            # 调用 Python 的统一构建任务
  gradlew
```

构建方式和变量见 [BUILD.md](BUILD.md)。本工程保留 Java、Smali、XML 及列明的二进制运行依赖；不能将其描述为全部恢复成原始 Java/Kotlin 的 AGP 项目。

下列目录只在维护者本地存在，不参与 GitHub 更新：

| 目录 | 用途 |
| --- | --- |
| `.private/` | 发布签名与私有认证材料 |
| `.local/` | 本机调试密钥等本地配置 |
| `tooling/cache/`、`.gradle/`、`build/` | 可重建的工具与构建缓存 |
| `dist/`、`releases/` | 安装包和发布留档 |
| `validation/`、`backups/` | 实车原始记录、原车组件和设备备份 |
| `references/`、`design/`、`experiments/` | 研究输入、设计草案和历史实验 |
| `archive/` | 旧构建和过时脚本的本地归档 |
| `docs/` 中的历史报告 | 发布过程、原始设备信息与分析记录 |

维护者旧资料索引保存在本地 `archive/project-maintenance-20261112/PROJECT_STRUCTURE.md`；本次没有删除车辆原件、固件或原始日志。历史归档不参与当前构建，不应重新作为源码基线。


## 仪表布局约束（1.2.41）

`E01InstrumentStyle` 统一保存值：`card`、`full`、`night`。旧 `mist` 值读取为 `night`，设置显示“夜航仪表”，旧雾蓝绘制类不再打包。夜航使用中央地图，不能归入fullscreen分支。

- `E01MapCard` 是视频窗口、协商流和安全边距的共同入口。夜航在1920×720参考屏上使用 `(400,174,1120,420)`，窗口比例7/12；请求视频保持8:3并按高度24、宽度8对齐。标准/较大/最大对应1152×432、960×360、768×288；不能仅缩小本地窗口而继续请求整屏视频。
- 夜航横向边距为 `ceil(finalWidth*67/350)`，对应整屏32%～68%关键内容区域；上下边距分别为最终高度的20%/8%，向内取整。物理尺寸声明按同一7/12窗口比例换算，缺失原始物理高度时回退58mm。`afterLoad` 避免二次缩小并按最终尺寸核对安全区。原有card/full样式参数保留。
- `E01NightInstrument` 在中央窗口外绘制不透明深蓝背景，窗口内左右200、上下66参考像素做渐隐阴影，边界不出现硬切。窗口外用四块独立矩形绘制，不能改回带孔的EVEN_ODD填充路径：1.2.39在E01实际合成时孔被填满，地图图层正常但前景遮住地图。运行时不重绘或移动原厂车速、转速、TBT及底部读数。
- `E01MusicCard` 夜航容器为 `(1515,185,370,380)`。封面在图片或尺寸变化时预合成到小型ARGB位图，普通绘图只显示该位图；避免车机旧GPU直接执行saveLayer/DST_IN。歌词更新不重建封面，分离标题文字与缓存图片。主文字28px、副文字24px（1920×720参考尺寸），两行主文字基线252/290、副文字342，夜航不绘制播放状态标签。缺少图片时保留音符，不伪造封面。
- `E01InstrumentPreview` 共用窗口计算、渐隐遮罩和夜航音乐绘制；车辆读数和地图为示意。过场限于避开原厂信息和音乐的中央区域。

相关回归在 `tests/mist_layout/run.py` 和 `tests/cluster_settings/test_mist_intro.py`，旧测试路径仅为兼容已有入口保留。测试覆盖请求尺寸、物理尺寸、安全区、像素阴影、封面预合成及缓存复用、元数据/封面保留、预览和过场取消。主机测试通过不代表已完成该版本实车验收。

1.2.40实机对照确认：1.2.39的地图独立图层正常而完整合成被前景盖住；改成四矩形外围后，用户重新打开地图的合成截图显示中央地图及阴影正常。请求尺寸1152×432和本地1120×420未改变，证明本次显示恢复无需重新调整地图居中参数。
