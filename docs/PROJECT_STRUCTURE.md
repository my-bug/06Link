# 工程结构

项目将源码、资源、构建工具与测试集中维护，主要目录如下。

```text
06Link/
  src/
    e01/                  # 全部参与编译的适配 Java
    core/smali/           # 其余完整运行源码
    main/                 # Manifest / res / assets / jniLibs / resources
    oem-bluetooth/        # 当前原车蓝牙兼容组件与脚本
    display-clock/        # 当前显示时钟实现
  scripts/                # 正式构建、工具解析、离线检查
  tooling/
    manifest.json         # 公开工具版本、来源和哈希
    compile-stubs/        # 仅编译使用的接口，不进入 APK
    java/                 # 签名工具源码
  tests/                  # 行为测试、固定夹具、源码集成契约
  gradle/wrapper/         # 固定 Gradle 启动器
  .github/                # CI 与反馈模板
  docs/                   # 必要工程说明
  project.json            # 版本与输入配置
  build.gradle            # 调用 Python 的统一构建任务
  gradlew
```

项目使用 Java、Smali、XML 和已配置的二进制运行依赖，构建方式与环境变量见 [BUILD.md](BUILD.md)。

`build/` 保存构建中间产物，`dist/` 保存安装包，`tooling/cache/` 保存下载的工具。这些生成目录由 `.gitignore` 排除。

## 仪表布局

`E01InstrumentStyle` 统一保存值：`card`、`full`、`night`、`relief`、`sport`。旧 `mist` 值读取为 `night`，设置显示“石墨仪表”，旧雾蓝绘制类不再打包。石墨与浮影共用中央地图窗口，独立于全屏样式。浮影使用中深灰背景、窄内沿和外扩软阴影；石墨使用灰蓝背景和轻柔渐隐。地图日夜颜色由手机导航提供，样式本身不修改视频颜色。

- `E01MapCard` 是视频窗口、协商流和安全边距的共同入口。石墨/浮影在1920×720参考屏上使用 `(400,174,1120,420)`，窗口比例7/12；请求视频保持8:3并按高度24、宽度8对齐。标准/较大/最大对应1152×432、960×360、768×288；请求尺寸随本地地图窗口同步调整。
- 石墨/浮影横向边距为 `ceil(finalWidth*67/350)`，对应整屏32%～68%关键内容区域；上下边距分别为最终高度的20%/8%，向内取整。物理尺寸声明按同一7/12窗口比例换算，缺失原始物理高度时回退58mm。`afterLoad` 避免二次缩小并按最终尺寸核对安全区。原有card/full样式参数保留。
- `E01NightInstrument` 在中央窗口外绘制不透明深蓝背景，窗口内沿28参考像素圆角轮廓做20参考像素渐隐阴影，边界不出现硬切。窗口外用四块独立矩形绘制，以兼容 E01 合成器对透明窗口的处理，避免背景遮挡地图。运行时不重绘或移动原厂车速、转速、TBT及底部读数。
- `E01MusicCard` 石墨/浮影容器为 `(1515,185,370,380)`。封面在图片或尺寸变化时预合成到小型ARGB位图，普通绘图只显示该位图；避免车机旧GPU直接执行saveLayer/DST_IN。歌词更新不重建封面，分离标题文字与缓存图片。主文字28px、副文字24px（1920×720参考尺寸），两行主文字基线252/290、副文字342，两种新式仪表不绘制播放状态标签。缺少图片时显示音符占位。
- `E01InstrumentPreview` 共用窗口计算、渐隐遮罩和石墨/浮影音乐绘制；车辆读数和地图为示意。过场由共用的 `E01RacingIntroRenderer` 绘制为 3 秒全屏竞速启幕，覆盖层退出后露出当前主题。

相关回归在 `tests/mist_layout/run.py` 和 `tests/cluster_settings/test_mist_intro.py`，旧测试路径仅为兼容已有入口保留。测试覆盖请求尺寸、物理尺寸、安全区、像素阴影、封面预合成及缓存复用、元数据/封面保留、预览和过场取消。硬件显示效果另行进行实车验证。

浮影的外阴影在地图窗口外 20 个参考像素内衰减，最大压暗18%，内沿仅 6 像素，中心遮罩完全透明；圆角与阴影由单一距离场预合成，避免四角重复叠加。绘制保留外围四个矩形与缓存 ARGB 位图，不依赖旧 GPU 的镂空路径。封面在与地图重叠的 5 像素区域保持透明，并按实际外阴影颜色融合；歌词更新不重新合成封面。地图和音乐沿用上述实拍坐标，Logo 位于参考坐标 (64,61)。

竞速样式由 `E01SportInstrument` 生成实际输出分辨率的缓存底板，保留同一地图窗口和原厂位置。斜切转速底板围绕 x1435～1835/y85～138 的原厂区域绘制，不绘制转速、车速、刻度或指示灯。地图开口采用四个独立裁剪区与透明 ARGB 位图，切角、细边和阴影统一合成。音乐卡片从同一底板采样背景，因此封面左缘能衔接真实底色与阴影。

石墨、浮影、竞速的底板、地图阴影和封面渐变不再额外叠加人工像素噪点；纯色区域保持均匀，阴影采用窄幅衰减，封面以80参考像素左渐隐按实际底色预合成。`E01InstrumentPrecision` 仅负责最终颜色通道的限幅和取整。副屏的石墨、浮影、竞速 UI 窗口显式请求 RGBA_8888；这是应用窗口格式，不代表已验证面板输出位深。地图视频解码格式、尺寸与帧率不因此改变。
