# 仪表主题与过场动画

仪表样式、设置预览和开屏动画共用主题定义。新增主题从 `src/e01/com/shilapi/xcertplay/E01InstrumentStyle.java` 的 `THEMES` 表开始，设置选项自动读取该表。

## 现有主题

| 保存值 | 显示名称 | 地图布局 | 边框材质 |
| --- | --- | --- | --- |
| `card` | 信息卡片 | 居中卡片 | GLASS |
| `full` | 全屏地图 | 全屏 | GLASS，仅音乐区域绘制卡片 |
| `night` | 石墨仪表 | 内嵌地图 | GRAPHITE |
| `relief` | 浮影仪表 | 内嵌地图 | RELIEF |
| `sport` | 竞速仪表 | 内嵌地图 | SPORT |

保存值用于设置兼容，不随显示名称变化。旧值 `mist` 和旧名称“夜航仪表”仍映射到 `night`；未知值使用 `card`。

## 源码分工

以下 Java 文件均位于 `src/e01/com/shilapi/xcertplay/`。

| 文件 | 职责 |
| --- | --- |
| `E01InstrumentStyle.java` | 主题表、名称、布局类型、材质颜色、音乐区域、动画裁剪区域和开关默认值 |
| `E01MapCard.java` | 视频尺寸与安全区、真实 Presentation 安装、音乐开关监听 |
| `E01InstrumentRenderer.java` | 实屏与设置预览共同使用的边框绘制入口；缓存路径、渐变和材质 |
| `E01NightInstrument.java` | 石墨、浮影、竞速的材质绘制；由统一入口调用 |
| `E01InstrumentFeather.java`、`E01InstrumentPrecision.java`、`E01SportInstrument.java` | 羽化、精度和竞速底图的静态图像处理 |
| `E01MusicCard.java` | 真实与预览共用音乐绘制；标题、歌词、封面、暂停状态仍由现有媒体数据更新 |
| `E01InstrumentPreview.java` | 加入示意地图、原厂读数占位；不再另画一套边框或音乐卡片 |
| `E01ClusterIntro.java` | 独立的过场覆盖层；读取主题布局，不控制导航或投屏通道 |
| `E01NativeUi.java`、`E01NativeSettings.java` | 从主题表生成选项，保存选择 |

预览音乐使用单独的示例状态，不修改真实歌曲状态。主题选择改变时才重建预览材质；重复选择同一主题复用缓存。日夜预览只改变示意地图和原厂文字颜色。

## 地图布局与居中

参考仪表为 **1920 × 720**。`E01MapCard.boundsFor()` 输出 `x、y、宽、高`，真实视频、预览和动画均调用它。

| 布局 | 地图区域 | 地图圆角 | 音乐区域 |
| --- | --- | --- | --- |
| CARD | `326, 122, 1267, 475` | 40 | `1515, 185, 370, 340` |
| FULL | `0, 0, 1920, 720` | 0 | `1515, 185, 370, 340` |
| INSET | `400, 174, 1120, 420` | 0 | `1515, 185, 370, 380` |

其他尺寸按比例计算。卡片比例为 `0.66`，内嵌比例为 `7/12`；视频协商高度对齐 24 像素、宽度对齐 8 像素，不能直接用 UI 的整数尺寸代替。

导航居中由发送给手机的安全区参与控制，不通过平移或裁切视频实现：

- FULL：左右各占最终视频宽度的 32%，上下各占高度的 22%。
- CARD：左右各占最终视频宽度的 `5/22`；上方 20%，下方 8%。
- INSET：左右各占最终视频宽度的 `67/350`；上方 20%，下方 8%。

安全区向内取整，始终基于最终协商视频尺寸计算。调整内容大小继续沿用 `E01DisplayConfig` 的物理尺寸处理，不另改上述边界。新增外框时先复用现有布局；若确实修改地图区域，必须同时验证真实视频、协议安全区、预览和动画。

## 原厂信息与音乐

原厂车速、转速、转向灯、底部状态图标和 TBT 卡片由车机显示。主题只绘制底板，不能用示意读数替换它们；预览中的读数和 TBT 虚线框仅用于标识位置。

音乐卡片在所有主题中使用同一个 `music_enabled` 开关。布局由主题的 `musicBounds()` 提供。歌曲、歌词、封面继续走 `E01MusicCard` 原有增量数据流程，主题不注册第二条媒体订阅。

内嵌主题采用四块互不重叠的外侧矩形留出透明地图区域。保留这个处理方式：E01 的 GPU 曾把复合路径的地图孔覆盖成不透明区域。

## 过场动画

只有一套过场：横线展开地图，总时长 **5000 毫秒**。界面、动画和设置读取共用的默认值；`transition_enabled` 默认开启，用户已保存的选择优先。

- 由既有仪表通道的开启回调触发，每次会话只播放一次。
- INSET 的动画区域限制在参考坐标 `405,190 → 1515,597`，避开原厂读数、TBT 和音乐区域。
- 其他布局沿用整屏过场，地图孔和圆角来自相同布局定义。
- 关闭动画、会话断开、窗口移除、动画取消或异常时，覆盖层立即隐藏。
- 独立的 **5500 毫秒**截止任务必须成功排入，才允许显示动画覆盖层；旧会话回调不能结束新会话动画。
- 动画不能发送地图开关、导航状态或阻塞解码，结束时直接露出已在播放的视频。

动画时间点直接以毫秒表示，不再从另一套时长换算。

## 新增主题

1. 在 `THEMES` 中添加唯一且稳定的保存值、显示名称、布局、材质和颜色。复用现有布局时，不修改地图安全区。
2. 若只换颜色，复用现有材质；若增加材质，在 `E01InstrumentRenderer` 或它调用的材质绘制器内实现，实屏和预览共用该实现。
3. 音乐仍使用 `E01MusicCard`；需要变更位置时调整主题布局，不分别修改预览坐标和真实 View 坐标。
4. 动画读取主题的地图区域、圆角、背景和裁剪区域。沿用现有生命周期，不为新主题复制一套投屏开关或动画状态。
5. 新增主题后检查选择弹窗是否还能容纳选项；不要加入每帧重新分配位图、路径或阴影的操作。
6. 补齐主题枚举、预览、原厂信息保留区和动画退出的测试；更新本文件及主题介绍、预览图。

## 验证

```sh
python3 tests/mist_layout/run.py --output /tmp/06link-theme-preview
python3 tests/cluster_settings/test_mist_intro.py
python3 scripts/build.py --variant release --offline
python3 tests/test_build.py
```

本地回归覆盖主题选择、旧值迁移、地图和安全区尺寸、预览与实屏绘制、音乐与歌词、材质缓存、窗口安装顺序，以及动画取消和超时退出。主机生成的预览不能代替车机合成效果；布局或材质变更后，还需检查实车原厂图标、导航中心和连续重连。
